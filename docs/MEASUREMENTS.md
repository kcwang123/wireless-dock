# V0.2 Measurement Checklist

Use calipers where possible. Record dimensions in millimeters.

## Shure SLXD2

- grip diameter at holder contact height
- maximum lower-body diameter
- bottom-cap diameter
- distance from bottom to taper start
- desired insertion depth
- preferred clearance around display/switches

## Shure SLXD1

- body width
- body thickness without belt clip
- body thickness including belt clip
- distance from bottom to belt-clip start
- bottom-corner radius
- antenna-root keep-out area
- battery-door keep-out area

## MIPRO ACT-5 handheld

- grip diameter at intended contact height
- lower-body maximum diameter
- distance from bottom to major taper
- desired insertion depth

## MIPRO ACT-7 handheld

- same measurements as ACT-5
- note any differences from ACT-5

## MIPRO ACT-5 bodypack

- width
- thickness without clip
- thickness including clip
- height to antenna root
- bottom geometry / corner radius

## MIPRO ACT-7 bodypack

- same measurements as ACT-5
- note any differences from ACT-5

## Sennheiser EK IEM G4

- body width at holder contact area
- thickness without belt clip
- thickness including belt clip
- bottom-corner radius
- antenna keep-out
- headphone jack / volume knob keep-out
- battery-door movement clearance

## Electronic tag

Once a display model is selected:

- PCB outer width
- PCB outer height
- total thickness
- visible screen width/height
- mounting-hole positions
- connector position
- cable/power exit direction

## Printed-interface calibration

Test:
- 0.20 mm per-side clearance
- 0.25 mm per-side clearance
- 0.30 mm per-side clearance

Evaluate:
- insertion force
- wobble
- repeated-cycle wear
- PETG elephant-foot sensitivity
- whether end-stop locking is required
